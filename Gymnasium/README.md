# SEARCH1DO Search-Based Planning in Advanced 3D Environments
This is a project made for the course "Introduction to AI" from the university of Milano-Bicocca. 

## Objective
Develop and test search-based planning algorithms in complex 3D environments, utilizing advanced 3D and physics simulation libraries such as NVIDIA Cosmos, NVIDIA Omniverse, Project Chrono, and PyBullet.

1. Integration with [Gymnasium](https://github.com/Farama-Foundation/Gymnasium/)
- [x]  Implement fundamental search algorithms (e.g. A*, uniform cost, etc )
- [x]  Evaluate algorithm performance in simple, physics-free 3D settings.
- [x]  Estimate computational cost based on environment characteristics
